## Prototype

`prototype/services/<slug>/index.html`, all 16 services, generated by
`prototype/scripts/gen-service-pages.py` from `prototype/services/_data/`
(items and FAQs read through the API, and the proposed Item Icons). Edit the
script, not the pages. `vite.config.js` adds every `services/*/index.html`
to the build. `data-field` = the bound field's display name;
`data-condition` = Designer conditional visibility (the generator leaves
out what a rule would hide).

Reused classes: Quote Hero + Quote Card (Toronto), Head Row Is Top + Head
Row Copy (About), Stat Accent, Service Card (+ Is Dark), Badge, Icon Tile
Is Small, Note Plate, Split + Compare, Values Panel / Values Photo (+ Shade,
Photo Caption) / Value List / Value Item / Value Icon (About), Head Center
+ Step Grid, Head Row + Card Grid + Reason Card, Locations Row + Tag List,
Faq Grid / Faq Item, CTA Banner.

New classes (prototype `src/css/new-classes.css` › "Service page", and in
Webflow): **Overview Stack**, **Situation Grid**, **Situation** (outlined
card), **Situation Text**, **Highlight Panel**, **Rich Body** (Text/Secondary;
child styles = MANUAL-TODO J), combos **Icon Tile › Is Light**, **Compare ›
Is Single**, **Note Plate › Is Center**. (Overview Panel, … Head, … Bar,
… Body were made for the first draft and removed.)

**Item Icons:** new module `item-icons` (prototype and repo
`src/modules/item-icons.ts`, run from `src/index.ts`): `[data-item-icons]`
on the tile list holds the field's comma list; each `[data-item-icon]` tile
box holds an Icon Size instance (20px) with Icon prop `ph`, and the module
adds the n-th name's class to its `<i>`. Tiles are sized by class, so
nothing moves when the script runs; with scripts off the five tiles have no
glyph (the "And more" tile is a fixed `ph-dots-three`).

Checked (headless, 1440 / 820 / 390, scripts off vs on, after the Figma
changes): page height equal, FAQ panels 0/8 open on first paint, 5 tile
icons with scripts on, no horizontal overflow; office-furniture-liquidation
(before/after pair) and e-waste-recycling (After Image alone).
